# Urukrama Kaushal: Portfolio 📊

A 3D animated "About Me" website: Streamlit app embedding a Three.js scene (wireframe core + neural-network particle field), glass cards with tilt effects, typing animation, and scroll reveals.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Customize
All content lives in `data.py` (the look lives in `template.html`). Replace the `TODO` GitHub/LinkedIn/project links and push.

## Deploy free (Streamlit Community Cloud)
1. Push this repo to GitHub.
2. Go to https://share.streamlit.io and sign in with GitHub.
3. Click **Create app**, pick this repo, branch `main`, main file `app.py`, then **Deploy**.
